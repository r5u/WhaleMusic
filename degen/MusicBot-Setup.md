# WhaleMusic setup

Use the current [WhaleMusic setup guide](../docs/SETUP.md) and [command guide](../docs/COMMANDS.md).

The earlier shared-wallet instructions have been replaced. Beer mL and Degen points are separate balances. The current rates are 10,000 Degen points for 100mL and 100mL for 1,000 Degen points. A local MongoDB replica set is initialized by the launcher. Redis is not required.
